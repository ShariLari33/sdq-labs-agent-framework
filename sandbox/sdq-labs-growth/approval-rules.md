# Approval Rules

All recommendations require human approval before external action.

## Auto-Allowed

- Reading imported synthetic performance data
- Creating analysis output
- Creating memory items
- Creating improvement candidates
- Requesting approval

## Requires Human Approval

- Marking a task as completed
- Applying any recommendation to a real ad account
- Creating or approving skill evolution proposals
- Changing budgets, bidding, keywords, audiences, ads, or landing pages

## Sandbox Constraints

- Never use real Google Ads credentials.
- Never modify tenants other than `sdq-labs-growth-sandbox`.
- Treat every dataset as synthetic.
