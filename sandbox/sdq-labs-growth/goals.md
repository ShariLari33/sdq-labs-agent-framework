# Goals

## Primary Objective

Generate qualified demo requests.

## Measurement

- Spend
- Conversions
- Conversion value
- CPA
- ROAS
- Campaign-level wasted spend
- Improvement candidates created by the agent
- Approval workflow completion

## Demo Success Criteria

- Baseline analysis identifies Broad Growth Experiments as wasted spend.
- Follow-up analysis shows lower CPA or improved ROAS.
- Validation analysis confirms the improvement largely persists.
- Approvals, memory, learnings, and improvement candidates are tenant-scoped.
